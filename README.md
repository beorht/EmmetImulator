# Emmet · Тетрадь

Интерактивный тренажёр [Emmet](https://emmet.io/) для начинающих верстальщиков. Слева — демонстрация: сокращение печатается и разворачивается в HTML прямо на глазах. Справа — тетрадь ученика: редактор в клетку, где нужно повторить приём, проверить решение и сразу увидеть результат.

Проект сделан по плану из [`docs/emmet_learning_project_plan.md`](docs/emmet_learning_project_plan.md).

## Возможности

- **Живая демонстрация.** Сокращение набирается по буквам и разворачивается в HTML в том же окне. Рядом показан итоговый результат. Анимация повторяется по кругу с паузой 1,5 с, её можно остановить, перемотать к результату или запустить заново.
- **Редактор-тетрадь** на CodeMirror 6: подсветка синтаксиса, нумерация строк, фон в клетку, `Tab` разворачивает сокращение Emmet.
- **Структурная проверка.** Сравнивается дерево DOM, а не текст: отступы, переносы и порядок атрибутов не важны. Сообщения об ошибках конкретные: «Внутри `<ul>` должно быть 3 × `<li>`, сейчас 2».
- **Только через Emmet.** HTML, набранный или вставленный руками, не засчитывается: такой фрагмент подсвечивается волнистой линией.
- **Безопасный предпросмотр** кода ученика в изолированном `iframe`.
- **32 задания:** 12 обучающих с демонстрацией и подсказками и 20 практических работ.
- **Доступность:** управление с клавиатуры, живой регион для сообщений, поддержка `prefers-reduced-motion`.

## Быстрый старт

Нужен Node.js 20.19+ или 22.12+ (требование Vite 8).

```bash
npm install
npm run dev       # сервер разработки → http://localhost:5173
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запускает сервер разработки с горячей перезагрузкой |
| `npm test` | Прогоняет тесты проверки ответов (Vitest + happy-dom) |
| `npm run build` | Собирает статический сайт в `dist/` |
| `npm run preview` | Раздаёт собранный `dist/` локально → http://localhost:4173 |

Результат сборки — обычные статические файлы, их можно выложить на любой хостинг (GitHub Pages, Netlify, nginx).

## Как пользоваться

1. Посмотрите демонстрацию слева: какое сокращение набирается и во что оно превращается.
2. Прочитайте условие справа и наберите в редакторе своё сокращение.
3. Нажмите `Tab`: Emmet развернёт его в HTML, и решение сразу проверится.
4. Если нужно, допишите руками текст или значения атрибутов и проверьте ещё раз.
5. Переходите к следующему заданию стрелками или точками в правом верхнем углу.

### Клавиши в редакторе

| Клавиши | Действие |
| --- | --- |
| `Tab` | Развернуть сокращение слева от курсора и проверить |
| `Ctrl` + `Enter` | Проверить (кнопка «Проверить» делает то же самое) |
| `Ctrl` + `]` / `Ctrl` + `[` | Увеличить / уменьшить отступ |
| `Shift` + `Tab` | Уменьшить отступ |
| `Ctrl` + `Z` / `Ctrl` + `Y` | Отменить / повторить |
| `Esc`, затем `Tab` | Выйти из редактора к следующему элементу страницы |

## Задания

Все задания хранятся в [`src/data/exercises.json`](src/data/exercises.json).

### Обучение

Каждое обучающее задание объясняет один приём. Демонстрация показывает его на другом примере, чтобы ученик решал по аналогии, а не копировал.

| № | Тема | Сокращение |
| --- | --- | --- |
| 1 | Первый тег | `p` |
| 2 | Класс через точку | `div.card` |
| 3 | Идентификатор | `header#top` |
| 4 | Вложенность | `nav>a` |
| 5 | Соседние элементы | `h2+p` |
| 6 | Повторение | `ul>li*3` |
| 7 | Текст внутри | `button{Купить}` |
| 8 | Атрибуты | `a[href=#about]{О нас}` |
| 9 | Нумерация | `ul>li.item$*3` |
| 10 | Подъём на уровень | `div>h3+p^button` |
| 11 | Группировка | `(header>nav)+main+footer` |
| 12 | Меню целиком | `ul.menu>li*3>a{Пункт $}` |

### Практика

20 самостоятельных работ: 4 простые, 3 средние и 13 сложных, от «Обёртки» до «Каркаса страницы». В практической работе есть только условие и образец итогового HTML с предпросмотром. Демонстрации, подсказок и готового решения нет.

## Как устроена проверка

Проверка проходит по шагам и останавливается на первой найденной проблеме:

1. **Пусто?** Предлагает набрать сокращение.
2. **Не развёрнуто?** Если в коде нет ни одного тега, напоминает нажать `Tab`.
3. **Набрано руками?** Редактор помечает всё, что ученик напечатал или вставил сам. Если среди этого есть угловые скобки, имена тегов или атрибутов, `=` или кавычки, решение не засчитывается. Руками можно вводить только текст внутри тегов и значения атрибутов. Пометки сохраняются при отмене и повторе, поэтому обойти проверку через `Ctrl+Z` нельзя.
4. **Ошибки разметки:** незакрытые и лишние теги, незакрытые кавычки, оборванный тег.
5. **Структура:** теги, их количество и вложенность сравниваются с эталоном.
6. **Детали:** классы, значения атрибутов и текст. Если структура верна, а детали нет, статус «Почти получилось».

Эталонный HTML не хранится отдельно: он получается развёртыванием `emmetExpression` через тот же пакет `emmet`. Поэтому эталон всегда соответствует сокращению.

## Как добавить задание

Добавьте объект в `src/data/exercises.json`.

Обучающее задание:

```json
{
  "id": "emmet-013",
  "title": "Название",
  "topic": "Приём Emmet",
  "description": "Условие для ученика.",
  "emmetExpression": "section>h2+p",
  "mode": "emmet",
  "validationMode": "structure",
  "difficulty": 1,
  "hints": ["Первая подсказка.", "Вторая подсказка."],
  "demo": {
    "abbreviation": "article>h3+p",
    "caption": "Пояснение под демонстрацией."
  }
}
```

Для практической работы укажите `"kind": "practice"` и не добавляйте `hints` и `demo`.

Правила:
- `demo.abbreviation` должно отличаться от `emmetExpression`.
- Поле `expectedHtml` можно не указывать: оно вычисляется из `emmetExpression`.
- В ожидаемом HTML пустое значение атрибута (`href=""`) означает «атрибут нужен, значение любое».

После добавления запустите `npm test`. Тесты проверят, что каждое задание и его демонстрация разворачиваются без ошибок и эталон проходит собственную проверку.

## Решения по открытым вопросам плана

Ответы на открытые вопросы из раздела 14 плана.

| Вопрос | Решение |
| --- | --- |
| Tab — проверка или отступ? | `Tab` разворачивает сокращение и сразу проверяет результат. Если сокращения нет, только проверяет. Для отступов есть `Ctrl+]` / `Ctrl+[` (или `Tab` при выделении). Кнопка «Проверить» тоже разворачивает однострочное сокращение, потому что на сенсорных клавиатурах нет `Tab`. |
| Где показывать результат кода ученика? | В сворачиваемом предпросмотре внутри панели редактора: `iframe sandbox=""` и CSP, скрипты и обработчики событий вырезаются. |
| Emmet или HTML? | Все задания в режиме `mode: "emmet"`. HTML, набранный руками, отклоняется (см. [проверку](#как-устроена-проверка)). |
| Переключение примеров | Демонстрация запускается при открытии задания и повторяется по кругу. |
| Прогресс и аккаунты | Их нет: отметки о решённых заданиях хранятся только в рамках сессии. |
| Левая визуальная область | Убрана. Сверху панель с логотипом и навигацией, ниже демонстрация и практика рядом, 50/50. |
| Целевое разрешение | От 1280×720. Проверено на 1366×768 и 1440×900 без прокрутки страницы. На экранах уже 960 px панели встают друг под друга. |
